# 热点情报台 MVP

一个可部署到 Cloudflare Pages 的轻量网页：热点榜、关键词筛选、按新鲜度/参考分排序、标题与快讯模板生成、原始新闻链接。

## 当前功能与边界
- 后端接口 `functions/api/news.js` 聚合公开 RSS：Google News（科技/汽车/全球）、BBC World、NPR。
- 前端从 `/api/news` 取数据。Cloudflare Pages Functions 会自动把 `functions/` 目录部署为 API 路由。
- 选题参考分是简单启发式分数，不是微博/小红书/X/视频号的真实热度，也不表示近一小时热度增速。
- 快讯是模板初稿，发布前必须核对事实、时间、数字、官方回应与原始报道。
- RSS 可用性、更新频率、地域可访问性由各来源决定；某些来源可能临时限流或不可达。
- 当前没有接入微博热搜、X Trends、小红书/视频号站内榜单。它们需要可用且合规的 API/授权服务；不要依赖未经授权的抓取或把不可验证的数据标为实时。
- 当前没有数据库和定时历史采样，因此不能计算真实的近 1 小时升温曲线。后续可加 Cloudflare D1 + Cron Trigger 存储采样数据；需根据当期免费额度评估。

## 部署到 Cloudflare Pages（尽量免费）
1. 登录 Cloudflare Dashboard，进入 **Workers & Pages**。
2. 创建 Pages 项目并上传本目录（或先推到 Git 仓库，再连接仓库）。
3. 框架预设选择 `None`；构建命令留空；输出目录设为项目根目录 `.`。
4. 部署完成后打开分配的 `*.pages.dev` 地址。首页应能访问，`/api/news` 应返回 JSON。
5. 如果新闻源无法访问，查看 `/api/news` 的 `sourceStatus.errors`，更换/移除不可用的 RSS 源。

## 建议后续版本
1. 加入 D1 数据库与 Cron Trigger：每 10–15 分钟记录标题、来源、发布时间和采集时间，计算趋势时明确标注“采样估算”。
2. 将“新闻源覆盖度”“多家媒体报道”“事件冲突/画面价值”“视频号适配”拆分成可解释评分，不把评分冒充平台热度。
3. 对微博、X、小红书、视频号逐个确认官方 API、授权供应商、费用、使用条款和地域限制后再接入。
4. 添加事件聚类、中文标题/摘要、去重、人工核实状态和收藏功能。
